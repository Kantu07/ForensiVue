DVR/NVR FORENSIC ACQUISITION REQUIREMENTS

The system should allow an investigator to acquire surveillance
video evidence and preserve its integrity.

Required information:

1. Evidence file
   - Original video file
   - File name
   - File format
   - File size

2. Source information
   - DVR/NVR vendor
   - Camera/channel number
   - Date and time of recording

3. Video information
   - Duration
   - Resolution
   - Frame rate
   - Bitrate

4. Integrity information
   - SHA-256 hash
   - Hash verification status

5. Analysis information
   - Video preview
   - Extracted metadata
   - Detected events/objects, if implemented

6. Final output
   - Standardized forensic evidence report
   - Evidence ID
   - Acquisition details
   - Hash value
   - Analysis results
