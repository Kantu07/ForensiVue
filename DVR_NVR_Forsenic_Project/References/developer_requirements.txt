DEVELOPER REQUIREMENTS

DEV 1 – CORE PROCESSING

The system should:
1. Accept a surveillance video as input.
2. Create an evidence ID.
3. Calculate SHA-256 hash.
4. Extract video metadata.
5. Preserve the original evidence file.
6. Perform basic video analysis.
7. Pass the results to the report module.

DEV 3 – GLUE / SCHEMA

Required evidence fields:

Evidence_ID
File_Name
File_Format
File_Size
Duration
Resolution
Frame_Rate
Bitrate
SHA256_Hash
Integrity_Status
Analysis_Result

DEV 4 – UI

The interface should provide:
1. Upload evidence button.
2. Evidence information display.
3. Video preview.
4. Metadata display.
5. SHA-256 hash display.
6. Integrity status.
7. Analysis result.
8. Generate Report button.

FINAL WORKFLOW

        ↓
